# Real Estate CRM

A full-stack Real Estate CRM web application built for managing leads, property listings, clients, deals, follow-ups, and analytics.

## Features

- Secure authentication with JWT
- Role-based access foundation for Admin, Manager, and Agent
- Lead management with status tracking
- Property management with listing details
- Client profile management
- Interaction logging
- Deal pipeline with stage updates
- Automatic commission calculation
- Reports and dashboard analytics
- Responsive frontend dashboard

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- Axios
- Lucide React

### Backend
- Node.js
- Express.js
- TypeScript
- Prisma ORM
- PostgreSQL (Neon)

## Modules Implemented

- Authentication
